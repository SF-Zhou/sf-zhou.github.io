# SF-Zhou's Blog [![Deploy](https://github.com/SF-Zhou/sf-zhou.github.io/workflows/Deploy/badge.svg)](https://github.com/SF-Zhou/sf-zhou.github.io/actions)

> A static blog based on GitHub Pages, GitHub Actions and [blogen](https://github.com/SF-Zhou/blogen).

## Build

The site is generated by [blogen](https://github.com/SF-Zhou/blogen), a Rust
static blog generator. Only the content (`posts/`), the configuration
(`blogen.toml`) and the blogen binary are needed — no external runtime.

```bash
# install blogen (once)
cargo install blogen --locked

# generate the site into ./public (profile/README.md when [profile] is enabled)
blogen build
```

During development, `blogen serve` builds the site, serves it at
<http://127.0.0.1:9000> and rebuilds/reloads on changes.

## Content

Articles live in `posts/`; metadata is encoded in the file name:

```text
posts/[2026.11.12 Rust,RDMA,RPC SF-Zhou]my-post.md
```

The first `# heading` line is the article title. Images referenced from
markdown are served from `posts/images/`. The tag `Hidden` excludes an article
from the index, RSS feed and profile while still generating its page.

## Configuration

`blogen.toml` controls site metadata (name, URL, language, author, analytics),
paths, the theme, giscus comments, RSS and the profile README. See the
[blogen configuration reference](https://github.com/SF-Zhou/blogen/blob/main/docs/config-reference.md)
for every option.

## Deployment

GitHub Actions installs prebuilt blogen with the [`install-blogen` action](https://github.com/marketplace/actions/install-blogen),
builds the site and publishes `public/` through the official GitHub Pages artifact workflow (`actions/upload-pages-artifact` +
`actions/deploy-pages`). One-time setup: in **Settings → Pages → Build and
deployment**, set **Source** to **GitHub Actions**. The generated profile README
is published separately to [SF-Zhou/SF-Zhou](https://github.com/SF-Zhou/SF-Zhou)
using the `TOKEN` secret.

## RSS Feed

The build process automatically generates an RSS feed at `public/rss.xml`
containing the latest 20 articles: <https://sf-zhou.github.io/rss.xml>
